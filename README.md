## Опис завдань (Варіант 8)

### Завдання 10.1: Послідовний пошук в масиві структур (Рівень В)
- Оголошення переліку спеціальностей `enum Spec { KN, IN, ME, FI, TN }`.
- Оголошення структури `Student` з анонімним об'єднанням `union` для третьої (профільної) оцінки:
  - `programuvannya` (для спеціальності «Комп'ютерні науки» `KN`);
  - `chyselni_metody` (для спеціальності «Інформатика» `IN`);
  - `pedagogika` (для інших спеціальностей: «Математика та економіка» `ME`, «Фізика та інф.» `FI`, «Трудове навчання» `TN`).
- Формування динамічного масиву з $N$ студентів та форматований вивід таблиці (9 колонок).
- Функції обчислення середнього балу для кожного предмету:
  - `AvgPhysics()` — середня оцінка з фізики;
  - `AvgMath()` — середня оцінка з математики;
  - `AvgProg()` — середня оцінка з програмування (для `KN`);
  - `AvgNumMethods()` — середня оцінка з чисельних методів (для `IN`);
  - `AvgPedagogy()` — середня оцінка з педагогіки (для `ME, FI, TN`).
- Функція підрахунку кількості студентів, які отримали з фізики оцінки «5» або «4» (`CountPhysics5or4()`).

### Завдання 10.2: Впорядкування та бінарний пошук в масиві структур (Рівень В)
- Інтерактивне текстове меню з вибором операцій:
  - `[1]` Введення даних з клавіатури;
  - `[2]` Вивід даних на екран у вигляді таблиці;
  - `[3]` Фізичне впорядкування даних (`Sort`);
  - `[4]` Бінарний пошук студента за багаторівневим ключем (`BinSearch`);
  - `[5]` Індексне впорядкування та вивід за індексами (`IndexSort`);
  - `[0]` Вихід.
- Критерій впорядкування для Варіанту 8:
  1. В першу чергу — номер курсу (за зростанням);
  2. В другу чергу — оцінка з третього (профільного) предмету (за зростанням);
  3. В останню чергу — прізвище за спаданням (у зворотному до алфавітного порядку).
- Індексне сортування методом вставок із масивом індексів `int* I`.
- Бінарний пошук студента `BinSearch` зі швидкістю $O(\log N)$ за вказаними курсом, оцінкою з 3-го предмету та прізвищем.

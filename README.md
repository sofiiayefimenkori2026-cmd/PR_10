## Багатомодульна структура проєкту (окремо Рівень А та Рівень В)

Кожне завдання реалізовано у вигляді окремих модулів із розділенням інтерфейсу (`.h`) та реалізації (`.cpp`):
- `student.h` — оголошення переліку `Spec`, структури `Student` та `extern const` масивів назв;
- `io.h` / `io.cpp` — введення даних та табличний вивід;
- `calc.h` / `calc.cpp` (для 10.1) або `sort_search.h` / `sort_search.cpp` (для 10.2) — алгоритмічна логіка;
- `Lab_10_...cpp` — головний модуль (`main()`);
- `UnitTest_10_...cpp` — модульні тести.
